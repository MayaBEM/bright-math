2 · แผนผังด่าน 26 ด่าน · แต่ละด่าน Learn → Practice → Boss Round (10 ข้อ จับเวลา 1–3 ดาว)

Practice ของแต่ละด่านหมุนเวียนมินิเกมตามป้ายสีเทา (ไฮไลต์ = มี Long Division Coach) · ด่าน G4 ใช้ partial quotients / area model ตามมาตรฐาน 4.NBT.B.6 ส่วน standard algorithm เต็มรูปเริ่มเป็นเป้าหมายหลักที่ G5–G6 (Coach ใน G4 เป็นตัวเลือกเสริม หาร 1 หลัก)

มินิเกม 8 แบบ

1 Area Model Builder — ลากเส้นแบ่งสี่เหลี่ยมตามหลัก เติมผลคูณย่อย รวมผล (ใช้กับ distributive/GCF ใน G6 ด้วย)
2 Partial Products / Quotients — เติมทีละบรรทัด มีป้ายบอกว่าบรรทัดนี้คือ 30 × 20 ฯลฯ
3 Long Division Coach — Divide → Multiply → Subtract → Bring Down ไฮไลต์ช่อง ผิดบอกทันทีว่าขั้นไหน
4 Estimate First — เลือก compatible numbers ก่อน แล้วค่อยคำนวณ เทียบผลกับค่าประมาณ
5 Decimal Point Drop — ลากจุดทศนิยมไปวางในคำตอบ เช็กด้วยการประมาณ
6 Factor Finder — หาคู่ตัวประกอบด้วยสี่เหลี่ยม (array) จำแนก prime/composite, GCF/LCM
7 Remainder Detective — ปัดขึ้น / ทิ้งเศษ / เศษคือคำตอบ / เศษเป็นเศษส่วน
8 Word Problems — หลายขั้น สถานการณ์จริง ชื่อหลากหลายวัฒนธรรม

5 · สิ่งที่ต้องการให้ยืนยัน

  1. ธีม — A Drafting Table (แนะนำ) / B Transit Lines / C Print Shop
  2. จำนวนด่าน 26 ด่าน (G4 = 9, G5 = 9, G6 = 8) → Set 1 = 52 หน้า + ปก/สารบัญ/เฉลย
  3. Long Division Coach ใน G4 — เปิดเป็นด่านเสริมหาร 1 หลัก (ตามที่ครูนิยมสอน) หรือคง G4 ไว้แค่ partial quotients/area model ตามมาตรฐานตรงตัว
  4. ชื่อระดับรางวัล — Point → Segment → Triangle → Square → Pentagon → Hexagon → Octagon → Circle ตามด้านบน หรือจะตั้งชื่อใหม่
  5. ข้อความในใบงาน/แอปทั้งหมดเป็นภาษาอังกฤษ สะกดแบบอเมริกัน ตัวเลขทุกข้อในเอกสารนี้ตรวจด้วยโค้ดแล้ว (Python Fraction/Decimal)
